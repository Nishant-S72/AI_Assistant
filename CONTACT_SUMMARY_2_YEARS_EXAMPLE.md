## How to View

1. Navigate to **Contacts** tab in the sidebar
2. Search for "Sarah Johnson" or "sarah.johnson@techcorp.com"
3. Click on the contact card
4. The summary will appear instantly with all the insights and recommendations

The summary is generated instantly using template-based logic that analyzes:
- Relationship duration (calculated from first message)
- Message count and patterns
- Task completion rates
- Contact tags and status
- Recent activity patterns
- Communication preferences
